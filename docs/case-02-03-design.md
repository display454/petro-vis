## w2：储层参数解释聚焦孔隙度

~~~text
合成数据与模拟岩心标定（始终可见）
┌参数────────┬深度对齐曲线────────────┬指标与选中────────┐
│情境/噪声   │模拟参考、kNN、密度公式 │MAE/RMSE/bias(pp) │
│每井标定数  │观察残差对应的位置     │n/total、覆盖率   │
│k/曲线组合  ├预测散点 y=x───────────┤范围外点数        │
│复位        │参考 vs 两种独立预测   │邻居局部差异      │
│模型/来源   ├残差随深度─────────────┤选中深度/曲线值   │
└────────────┴───────────────────────┴──────────────────┘
~~~

默认4训练井各240点、每井24个模拟标定点，共96；目标320点，seed1802、standard、noise1、四曲线、k9。固定哈希排序预算前缀6/12/24/48每井，便于同数据下比较。不能根据目标成绩重新挑点。特征只设“四曲线/仅RHOB”两档，避免参数面板失控。

密度公式基线独立，ρma=2.65、ρf=1g/cm³只读说明；允许负/越界结果以暴露假设问题，不偷偷裁到0—1。曲线值/预测为v/v，图可换算%；误差乘100显示“孔隙度百分点pp”，不是相对误差百分比。

同一sampleIndex连接深度轨、散点和残差。箭头键移动，Enter确认、Esc取消；全井指标不因选中改变。初始选中为空。局部邻居标准差只能叫“邻居标定差异”，不能画成校准置信带；范围外提示不自动宣判错误。

scenario=shift改变目标流体/观测关系，训练井与潜在目标参考不变。默认标准MAE约0.80pp(kNN)/1.81pp(公式)，shift约1.79/2.83；结果只反映教学生成器。当前没有FORCE独立岩心真值，不把其NPHI或预测当作岩心标定。该合成目标井允许交互探索，不能再称未参与调参的最终测试集。

背景依据：[SLB Measuring Porosity Downhole](https://www.slb.com/zh-cn/resource-library/oilfield-review/defining-series/defining-porosity)。文中讨论骨架、流体与泥质影响；项目系数为教学假设，无原文图片/数据复制。

## w3：从像素检测正弦候选

~~~text
合成灰度图；几何候选需要人工确认（始终可见）
┌图像条件────┬原图────────┬暗线增强/候选叠加─┬指标────────┐
│情境/噪声   │方位0—360° │共享方位与深度轴  │TP/FP/FN    │
│可见度      │深度向下    │全部结果，不藏误检│P/R/F1      │
│阈值        │null方位纹理│选中候选高亮      │容差/可见覆盖│
│图层开关    ├────────────┴──────────────────┤选中几何参数│
│复位        │候选列表：score/support/匹配身份│失败解释    │
└────────────┴───────────────────────────────┴────────────┘
~~~

128×256像素，灰度0—1，null未观测；深度起点2500m、步长0.02m，横轴方位0—360°。默认seed1803、noise.06、visibility.8、standard、阈值.45；最大展示结果12。画布用Canvas，叠加曲线可SVG；像素来自image.pixels，曲线只能来自搜索输出，不从reference复制成“检测”。

先prepareImage得到垂向暗线强度，再searchSinusoids搜索与去重。阈值只筛缓存候选；图层/选中只绘制，不能重新生成图像或搜索。改噪声/可见度/情境才生成/预处理/搜索；界面可显示计算中并合并拖动事件，最终状态必须匹配最新参数。

点击任一候选在两图同时高亮，列表为键盘入口，方向键/Enter/Esc可操作；使用稳定candidate.id而不是筛选后的数组下标。降低阈值后显示新增候选，包括误检；阈值排除选中对象时清旧明细。关闭真值只影响图层，评价照算。

候选score为像素响应，不是概率。只显示中心深度、几何幅度和相位；相位不是校正后的倾向，像素幅度不是开度。参考fractures参加对象评价，distractors不参加：bedding情境会把层理候选算FP，正好说明仅凭几何不足以认定天然裂缝。

匹配固定中心差≤5px且整周期RMS≤4px，一对一先最多命中再最小距离。禁止用背景像素准确率替代。默认3/0/0，方位缺失3/1/0、层理3/1/0、低可见度.3为0/0/3、噪声.18为3/2/0（均TP/FP/FN）。这些是当前合成实验的真实输出，不是强制UI目标。

几何背景依据：[US EPA Borehole Acoustic Televiewer](https://www.epa.gov/environmental-geophysics/borehole-acoustic-televiewer-atv)。本图仅借用展开几何，不模拟电/声成像仪器的真实物理响应。
