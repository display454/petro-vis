# 案例 1 具体设计：多曲线测井智能分层

编号 w1；ID welllog-multicurve-segmentation。本文记录 R01 设计，R02 当前实现为 ready 1.0.0，交付与验证见第 6 节。对应主规划第一个案例，不再以开发顺序把 w4 称作“案例 1”。

## 1. 叙事与边界

题目：**从连续曲线中，找出地层的边界。**

问题：测井响应连续且带噪，解释者要确定哪些变化值得划为候选界面。难点是薄层、弱对比层、不同曲线量纲，以及过分段与欠分段的取舍。

本例演示无监督的多曲线变点检测，不训练神经网络，不把曲线突变自动等同于正式地质层位。输出为候选界面、拟合段和需复核位置。真值是合成生成器的界面，仅用于教学评价。

面向初学者的三次收获：

1. 读懂深度轴、GR、密度、电阻率分别是什么。
2. 看懂数据如何变成算法输入，方法替代人工的哪一步。
3. 在同一口井上观察惩罚、最小层厚与噪声如何影响漏检和误检。

## 3. 案例流程 Tab

六步固定链条：

1. 选择教学井与难度：看到相同种子和潜在界面；确认不是实测数据。
2. 对齐与质控：深度严格递增、曲线等长；当前合成模式不含缺测，真实井需先处理。
3. 特征变换：RDEP 取 log10；再将各曲线转换为 z 分数。显示原量纲与标准化小图，说明直接相加会让大数值曲线主导结果。
4. 惩罚最优分段：求分段拟合误差与复杂度之间的折中；显示分段目标示意，不渲染成神秘“AI 输出”。
5. 界面匹配与误差定位：容差 ±0.5 m，参考与预测一对一匹配；可见 TP、FP、FN 的图形含义。
6. 人工复核：优先看薄层、曲线意见不一致和参数敏感位置；不把自动结果直接当最终解释。

流程 stats 使用实际输入规模、采样间隔和容差。workflow.metrics.html 包含一张总体数据流、一组标准化前后小图、一对一匹配示意与指标说明；steps 保留操作与坑点。原框架无需认识新的 flowchart 字段。

## 4. 可运行示范

### 4.1 数据

固定 n=480、深度 1550—1609.875 m、间隔 0.125 m。GR 单位 API、RHOB 单位 g/cm³、RDEP 单位 Ω·m。模拟砂岩、泥岩、致密碳酸盐岩的典型响应差异，只作教学示意，不声称是某油田的标定模型。

三个井段预设：

- standard：常规层段，界面响应较清晰。
- thin：增加厚约 0.75 m 的薄泥岩层，用于研究薄层与惩罚、最小层厚。
- spike：常规层段加入孤立尖峰，比较噪声与真实层界的差别。

seed 默认 1801。“换井”改变 seed；noise 改变观测扰动，保持同一 seed 的潜在界面。dataset 与 reference 单独保存；所有预测函数只能收到 dataset 派生的观测特征。

### 4.2 主算法与基线

主算法目标：

~~~
J = 各分段内标准化特征 SSE 的通道平均值之和
    + penalty × 内部边界数
约束：每段样本数 ≥ ceil(最小层厚 / 0.125)
~~~

动态规划求全局最优分段，前缀和计算区间 SSE。复杂度 O(n²p)，n=480、p≤3，优先用同步计算验证预算，暂不引入 Worker。

基线：比较相邻两个 4 样本窗口的均值差，用 RMS 聚合曲线，选择超过阈值的局部峰并做最小间距抑制。基线与主算法使用相同输入和同一评价；基线不是主算法结果加扰动得到的假对照。

### 4.3 默认控件

| 控件 | 范围/默认 | 预期变化 |
|---|---|---|
| 井段预设 | standard / thin / spike，默认 thin | 换地质教学情境 |
| 噪声 | 0—2，步长 0.05，默认 0.35 | 相同潜在层界下观测更模糊 |
| 分段惩罚 | 0.2—32，步长 0.2，默认 4 | 越大通常界面越少；错漏关系用结果说明 |
| 最小层厚 | 0.25—3 m，步长 0.125，默认 0.75 m | 限制碎片，过大可能合并薄层 |
| 特征 | GR / GR+RHOB+RDEP | 比较单曲线与融合 |
| 基线阈值 | 0.2—2，步长 0.05，默认 0.65 | 基线敏感度变化 |
| 显示参考界面 | 默认开启 | 仅改变叠加显示，不改变预测 |
| 换井 / 复位 | seed+1 / 恢复所有默认值 | 复现与探索 |

不增加无任务价值的“AI 强度”“智能程度”等参数。所有值由 app.js 单一状态管理，参数语义见 interfaces-v1。

### 4.4 布局与联动

桌面：左侧控件；中部共享深度的三轨曲线、预测拟合与边界；右侧 P/R/F1、匹配误差、基线结果和当前深度读数。

参考界面使用灰色虚线，模型界面使用深绿实线，基线界面使用铜色短标，漏检用空心圆/文字，误检用叉号。不能只凭红绿区分。参考岩性柱仅是合成情景说明，不参与模型输入。

光标在主图移动，所有轨道同步相同深度；点选预测界面或错误标记，在检视区显示预测深度、匹配参考深度、误差或“无匹配”；不在悬停时重跑算法。窄屏按轨道纵向重排并保持可读轴标签。

### 4.5 评价

容差固定 0.5 m。使用最大一对一匹配数，匹配数相同时最小化总距离。P=TP/(TP+FP)，R=TP/(TP+FN)，F1=2TP/(2TP+FP+FN)。MAE 仅统计匹配点的绝对深度偏差。

零界面情况按接口中的 null 定义呈现“不适用”；不能用逐采样点准确率替代界面指标。参考条数、预测条数、容差始终可见。

## 5. 三个验收实验

| 实验 | 固定条件 | 操作 | 验证内容 |
|---|---|---|---|
| 惩罚折中 | 同 seed、同噪声、同特征 | 惩罚从低到高 | 预测边界数量总体不增加，过高会漏界面；图和指标同步 |
| 最小层厚 | thin、同 seed | 最小层厚增至超过薄层 | 不产生小于约束的分段，薄层可能合并，可解释 FN |
| 单/多曲线与噪声 | 同 seed | 切换特征及噪声档位 | 实际重算，结果可变；不预设融合永远优于单曲线 |

Node 确定性测试覆盖无噪阶跃、常量、最小段长、惩罚单调性、固定种子、量纲变换、最大匹配、空结果、基线和非法输入。正式 UI 另验拖动、选择、复位、Tab、窄屏、原框架导入与卸载。
