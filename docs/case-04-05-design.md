## 共用边界

每例自带 data.js/core.js，B 写 index.html/demo.css/app.js。无外部库、fetch、包外路径。沿用浅纸色、深绿、铜色的研究工作台，不重做全站风格。至少 12px 的信息文字、键盘可操作、390px 无整页横向溢出。所有指标来自当前内核计算，静态图文只作为明确标注的默认实验快照。

默认显示验证井；训练井显示“训练回代”，测试井显示“冻结设置的测试展示”。来源抽屉显示许可、SHA、4/1/1 井清单及样本选择限制。已有曲线为公开观测，岩性为人工解释参考；不宣称生产级性能。

## w4：按深度连接三种证据

~~~text
标题 / 数据身份 / 验证或测试状态
┌参数─────────┬交会图──────────────────┬指标───────────┐
│井、k(验证)   │GR × RHOB（轴可换）     │固定四类宏 F1  │
│轴 x/y       │点按/键盘定位一个样本   │accuracy + 覆盖│
│类别过滤     │参考未知=灰方，拒判=三角│多数类独立基线 │
│只看已知错判 │图例带形状与中文名称    │选中点与投票占比│
├────────────┴────────────────────────┤               │
│深度：参考柱 / 预测柱 / 错判位置      │               │
└─────────────────────────────────────┴───────────────┘
混淆矩阵：固定四类 + 未映射参考行 / 拒判列，可点选
~~~

主问题是“为什么准确率看起来高，小类却没有识别出来”。默认验证结果：kNN 宏 F1 20.40%，多数类基线 22.05%；测试准确率 79.14%、固定四类宏 F1 22.36%。两个小类召回为 0，应引导看矩阵与深度位置，不能把这些结果修饰成全面提升。

模型输入固定四曲线（RDEP 先 log10），显示轴可以换，轴换不训练。k 候选 1/5/9/15 仅在训练/验证允许探索；测试锁 k=15。模型无自动未知类检测：缺特征才拒判，低票不自动变未知。投票占比不是校准概率。

一个 selection 以 sampleIndex / range / confusion 三选一，互相切换清旧来源。hover 或方向键定位样本，Enter 选中，Esc 清除；矩阵用原生按钮表格；过滤不重算模型也不改全井指标。密集点允许降低非选中点透明度，不能让未知参考消失。类别名称来自 D.classes。

空态：过滤后 0 点保留轴和原因；无已知参考显示分数不适用且矩阵仍有未知行；单类井保留全部轴并说明固定四类平均；异常清空旧指标、role=alert。公开数据本批无曲线缺失，拒判/缺失形态需用明确的合成结构 fixture 验证，不修改正式数据或伪称真实失测。

## w5：先隔离答案，再作同区对比

~~~text
标题 / GR 修复 / 验证或冻结测试 / 数据来源
┌参数─────────┬全井段曲线────────────────┬两法指标────────┐
│井           │可见 GR 实线，遮挡浅底带  │n_eval/n_masked │
│遮挡 0—30%   │插值点线 / 岭回归长虚线   │MAE RMSE R²     │
│两法/单法显示│RHOB/NPHI/RDEP 辅助轨     │各自预测覆盖率  │
│真值显示     │原生缺口斜纹（本批为0）   │共同点数及差值  │
├────────────┴──────────────────────────┤选中深度读数    │
│缺口列表 → 局部曲线与残差对齐放大      │方法参数只读     │
└───────────────────────────────────────┴────────────────┘
~~~

目标固定 GR；λ=10、三特征和训练井固定，优先把遮挡实验和局部复核做好，不增加目标曲线或模型参数面板。ratio 改变只重新遮罩/修复；切方法、真值显示、选择、缩放仅渲染。每次两法接收同一个 mask.visible，且各自独立，不读取原始 GR 答案。

默认 seed='r03-w5-01'、15 点块、15% 遮挡，实际两口 holdout 均为 75 点。原生缺口数=0；图例可以解释，但不能制造一段原始有值的数据再标成“真实失测”。测试中的 genuine null fixture 是结构测试，不混入公开实验界面。

指标用 API 单位，负 R² 保留；真值方差为 0 时“不适用”。若有未修复点，显示 n_eval<n_masked 与覆盖率，不记作零误差。两法差值/胜出数只用共同可预测点。默认测试中插值有 50/75 点误差更小，岭回归只有 25/75 点更小却有较低总体 MAE，应结合大残差解释，不能硬编码“多数点胜出=总体更好”。

点击缺口后默认展示首个点，键盘在段内逐点移动；真实未知点只显示估计和“无真值，不评价”，不写残差。无遮挡、只有原生缺口、辅助曲线缺失、两法都无预测均有空态。
