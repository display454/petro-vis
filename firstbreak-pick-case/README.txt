初至波自动拾取 · 示范案例包
==========================

这是什么
--------
一个可以直接上传到「可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（firstbreak-pick-case）整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到「物探 · 初至波自动拾取」场景，三个 tab 立即出现。

文件清单
--------
  case.json          清单：元信息 + 专业背景 + 案例流程（必需）
  demo/index.html    示范页（整页模式，沙箱 iframe 中运行）
  demo/demo.css      示范页样式
  demo/demo.js       STA/LTA 拾取算法与绘图
  README.txt         本文件

示范内容
--------
拖动「噪声水平」与「触发阈值」两个滑杆，观察 STA/LTA 能量比法：
  · 噪声调高 → 噪声尖峰提前触发 → 假拾取；
  · 阈值调高 → 比值峰够不到 → 漏拾取；
  · 恰当参数下误差 ≤ 2 个采样点（4 ms）→ 命中。
对应案例流程里的「空间一致性约束」与「低置信度人工复核」两步。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和两块正文即可；
demo/ 文件夹换成你自己的页面或脚本也一样能传。
